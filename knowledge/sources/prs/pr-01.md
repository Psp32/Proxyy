# Overview

Implemented fixes and improvements to the resume export system in urCV.ai. This contribution addressed multiple issues affecting PDF, Word, and image exports, including missing Coding Profiles, incorrect template styling in Word documents, clipped image exports, and incomplete PDF template rendering.

The PR also improved export reliability across the different resume templates by changing how content is rendered and captured.

# Problem

The resume export functionality had several issues:

- Coding Profiles were not appearing in PDF and Word exports.
- Word exports did not respect the resume template selected by the user.
- Image exports could cut off content near the bottom of the resume.
- PDF templates were missing the Coding Profiles section/link.
- Resume templates used height and overflow constraints that could interfere with complete export rendering.

# Key Changes & Implementation

## PDF Generation

- Fixed PDF generation by removing an unnecessary `await` from the synchronous `generatePDF` function.
- Added Coding Profiles to PDF generation across all supported templates:
  - Default
  - Modern
  - Professional
  - Creative
- Added the Coding Profiles section/link to PDF templates.

## Word Document Generation

- Added a `templateName` parameter to Word document generation.
- Updated Word generation so that the selected resume template controls the styling of the generated document.
- Added template-specific styling for:
  - Modern
  - Professional
  - Creative
- Added Coding Profiles to Word exports.

## Image Export

- Improved `html2canvas` capture behavior.
- Improved element selection during screenshot/export.
- Added overflow handling to ensure the complete resume is captured.
- Removed restrictive `max-height` and `overflow-y-auto` constraints from resume templates.
- Increased `min-height` values to support complete content rendering.
- Added explicit `overflow: visible` styling to prevent content clipping.
- Improved rendering of the hidden preview element used during export.
- Added appropriate styling and rendering delays before capture.

## UI / Footer

- Simplified the footer component layout.
- Added technology-stack tags to the footer.

# Bugs Fixed

1. Coding Profiles were missing from PDF exports.
2. Coding Profiles were missing from Word exports.
3. Word exports ignored the user's selected resume template.
4. Image exports could cut off the bottom portion of the resume.
5. PDF templates were missing the Coding Profiles section/link.
6. Resume content could be clipped because of height and overflow restrictions.

# Impact

This contribution improved the reliability and consistency of resume exports across PDF, Word, and image formats.

Users can now:

- Export Coding Profiles together with the rest of their resume.
- Generate Word documents that respect their selected resume template.
- Export complete resume content without the bottom portion being clipped.
- Use the supported resume templates more consistently across export formats.
