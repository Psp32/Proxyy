# Overview

Added an `examples/` directory to Layr containing sample project plans generated directly using the Layr VS Code extension.

The examples demonstrate the structure, organization, and level of detail that Layr can produce for different types of software projects.

The goal was to make the extension's capabilities easier for new users and contributors to understand by providing concrete examples of real Layr-generated output.

# Problem

New users and contributors needed a way to understand what Layr-generated project plans actually look like.

Without concrete examples, it can be difficult to understand:

- The structure of generated plans.
- The level of detail produced by Layr.
- What kinds of projects Layr can plan.
- What the generated output looks like before using the extension.

# Key Changes & Implementation

## Examples Directory

Added a new `examples/` directory containing sample project plans generated using Layr.

The examples were created directly through the Layr VS Code extension.

## Included Examples

### Todo Application

Added a sample project plan for building a Todo application.

This demonstrates how Layr structures a plan for a common application-development project.

### Portfolio Website

Added a sample project plan for building a portfolio website.

This demonstrates how Layr can generate structured planning output for a frontend/web project.

### REST API Backend

Added a sample project plan for building a REST API backend.

This demonstrates Layr's ability to produce plans for backend/API-oriented projects.

# Source Integrity

An important aspect of this contribution is that the example plans were:

- Generated directly using Layr.
- Copied into the repository as generated.
- Not manually modified after generation.

This means the examples serve as representative evidence of the extension's actual output rather than manually curated documentation.

# Purpose

The examples directory serves several purposes:

- Demonstrates Layr's capabilities.
- Helps new users understand generated output.
- Helps contributors understand expected plan structure.
- Provides concrete examples for different project categories.
- Makes the generated planning format easier to evaluate.

# Impact

The contribution improved Layr's onboarding and documentation experience by providing concrete examples of its generated output.

Instead of explaining the extension's capabilities only through prose, users can inspect actual project plans generated by the tool.
